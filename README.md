# doom_robot_mark_1

> 一台桌面小机器人的**大脑**：0.36 寸小屏上的表情、会淡掉的心情、能听会说的语音、联网查资料、跨会话记忆。
> 硬件只有麦克风、喇叭、一块小屏和摄像头——**没有轮子，它不会动**。

这是 [DeepSeek Harness](https://deepseek.com)（DSH）的一个插件。机器人本体跑固件，脑子跑在电脑上的 DSH 里：
ESP32 负责录音、放音、画脸、拍照，DSH 负责听懂、思考、说话，并且**只下发受限指令**。

```
┌──────────── 机器人（ESP32-S3）────────────┐        ┌──────── 电脑上的 DSH ────────┐
│ INMP441 ──I2S──► 录音 ─┐                  │        │  dsh-esp32-robot 插件        │
│ MAX98357A ◄I2S── 播放 ─┤  WiFi / HTTP     │◄──────►│  ① 网关  ② 语音识别           │
│ SSD1306 ◄I2C── 表情 ───┤  （局域网）      │        │  ③ DeepSeek 会话  ④ 语音合成  │
│ OV2640 ──DVP──► 抓帧 ──┘                  │        │  ⑤ 受限工具（表情/搜索/看）    │
└───────────────────────────────────────────┘        └──────────────────────────────┘
```

## 它现在会什么

| 能力 | 说明 |
|---|---|
| 表情 | 10 种情绪（平静/开心/兴奋/好奇/思考/聆听/说话/困/难过/困惑），屏幕上只有眼睛和嘴 |
| 心情 | 会自己慢慢淡回平静，深夜自动变困；**整个模块可以一键关掉** |
| 说话 | 系统自带语音（Windows 用 SAPI，macOS 用 `say`），边合成边发，第一句最快出来 |
| 听 | 16k 单声道 PCM 进来，转成文字再交给大脑 |
| 记忆 | 热记忆（每轮自动带上）+ 结构化记忆（Mnemon，跨会话可检索） |
| 查资料 | 联网搜索，用宿主配置的搜索服务 |
| 看 | 摄像头抓帧（需要设备上传过画面） |

它**没有**的能力：文件、命令、生图、QQ、浏览器……这些都通过 `tools.restrict` 从它的工具表里删掉了，
每轮只发 8 个工具给模型——这是最省 token 的配置。

## 安装

挑一个平台照着做（两份说明内容一样，只是路径写法不同）：

- **Windows** → [`docs/INSTALL-WINDOWS.md`](docs/INSTALL-WINDOWS.md)
- **macOS** → [`docs/INSTALL-MACOS.md`](docs/INSTALL-MACOS.md)

最短路径：

```
1. 把 plugin/ 整个目录放到一个固定位置（别放在临时目录）
2. DSH → 插件管理 → 从本地目录安装 → 选这个 plugin 目录
3. 重启 DSH
4. 左侧栏点「机器人」→ 点「试一句」听到它说话
```

## 目录

```

  client.js           网页半边：左侧栏那个页面

```

## 设计上的三个决定

**1. 脑子放电脑上。** ESP32 跑不动像样的模型；放电脑上还能直接用 DSH 的会话、记忆和人格配置。代价是断网就变傻。

**2. 语音是 16k 裸 PCM。** MAX98357A 只吃 I2S 数字音频，服务端直接给 PCM，固件不用带解码器、不用大缓冲。

**3. 能力白名单。** 模型只能调用 8 个工具，参数有硬上限，服务端不注册就等于没有。它碰不到这台电脑。

## 省 token 是怎么做的

每轮进模型上下文的东西只有三样：人格（固定）、身体说明书（约 10 行）、工具 schema（8 个）。

- 记忆工具从 13 个砍到 4 个（`runtime_memory` / `remember` / `recall` / `forget`）——
  Mnemon 的几个 schema 特别大，砍掉 9 个等于每轮省下上千 token
- 固定的行为约束合并进「身体说明书」，不再单独占一段 `{{robot_rules}}`
- 工具描述压到一句话，emoji 表情列表走 enum，不写进描述

## 协议速览

```
POST /robot/api/turn        音频或文字进 → 「一行 JSON 头 + 16k PCM 流」出
GET  /robot/api/ping        握手 + 同步心情（每 10~30 秒一次）
POST /robot/api/frame       上传一帧 JPEG
GET  /robot/sim             电脑麦克风/喇叭模拟器
```

完整字段见 [`docs/02-架构与协议.md`](docs/02-架构与协议.md)。

## 硬件

引脚、I2S 参数、OLED 接线、供电都在 [`docs/03-固件与硬件.md`](docs/03-固件与硬件.md)，
可烧的代码在 [`firmware/`](firmware/)。

核心约束：摄像头吃掉 12 根脚，N16R8 的 GPIO33~37 被 PSRAM 占用，真正自由的只有 11 个。

> ⚠️ 固件**没有在真实硬件上验证过**。按 `firmware/README.md` 里的「上板顺序」一步步来，
> 别一次全接上——先单测麦克风，再单测功放，最后才跑整条链路。
