# 固件与硬件

> **可烧的代码在 [`../firmware/`](../firmware/)**（PlatformIO 工程，含接线、上板顺序、要调的参数）。
> 这一篇是设计说明：为什么这么接、这些参数为什么是这个值。

> ⚠️ 引脚表是按**常见的 ESP32-S3-WROOM CAM 板**（Freenove / 同类）排的。你的板子到货后，
> **第一件事是用厂家例程跑通摄像头**，把它的引脚表抄下来对一遍，再写自己的代码。
> 引脚错一个，摄像头就是花屏或全黑，很浪费时间。

## 一、引脚预算（这是最紧的资源）

ESP32-S3-N16R8 上，能用的引脚其实不多，大部分被占掉了：

| 被谁占了 | GPIO | 说明 |
|---|---|---|
| SPI Flash | 26~32 | 绝对不能动 |
| **八线 PSRAM** | **33~37** | **N16R8 的坑**：这 5 个脚被 PSRAM 占用，用了一定崩 |
| USB | 19、20 | 下载和串口 |
| 摄像头 DVP | 4~13、15~18 | 12 根，最吃引脚 |
| Strapping | 0、3、45、46 | 上电电平决定启动模式，尽量别接外设 |

**真正空出来的只有 11 个：`1 2 14 21 38 39 40 41 42 47 48`**

这台机器人**没有轮子**（不装电机），所以省下 4 个脚给屏幕和电池检测：

| 用途 | GPIO | 备注 |
|---|---|---|
| INMP441 `SCK` | 41 | I2S0 位时钟 |
| INMP441 `WS` | 42 | I2S0 左右时钟 |
| INMP441 `SD` | 40 | I2S0 数据输入 |
| MAX98357A `BCLK` | 14 | I2S1 位时钟 |
| MAX98357A `LRC` | 21 | I2S1 左右时钟 |
| MAX98357A `DIN` | 47 | I2S1 数据输出 |
| **OLED `SDA`** | **1** | I2C，0.36 寸 SSD1306 |
| **OLED `SCL`** | **2** | I2C，400kHz |
| 电池电压 | 48 | ADC，分压后 |
| 备用 | 38、39 | 留给以后的按钮 / 传感器 |

> 以后要加轮子，`38 39` 之外还能用 I2S 全双工共用时钟省 2 个脚。

### 0.36 寸 OLED（SSD1306 72×40）

| 项 | 值 |
|---|---|
| 尺寸 | 0.36 寸，通常 72×40 像素（少数是 64×48，接线一样） |
| 驱动 | SSD1306，I2C 地址 **0x3C**（有的模块背面能改成 0x3D） |
| 接线 | VCC→3.3V、GND、SDA→GPIO1、SCL→GPIO2（4 根线） |
| 库 | Arduino 用 `U8g2`（`U8G2_SSD1306_72X40_ER_F_HW_I2C`）最省事 |

**为什么用 72×40**：这么小的屏只够画两只眼睛和一张嘴。表情不靠文字、不靠图标，靠**眼型 + 嘴型**——
所以服务端只发一个情绪名字，屏幕自己按表画。表情表在 `plugin/lib/face.js`，面板里有实时预览，
固件照着同一张表画就完全一致（字段含义见 `04-插件用法.md` 的「表情表」）。

> 换屏（比如 1.3 寸 128×64）时，只要把 `SCREEN` 里的坐标按比例改掉，表情表本身不用动。


> 如果引脚实在不够：I2S 可以**全双工共用时钟**（只多一根数据线，省 2 个脚），
> 代价是麦克风和喇叭必须同采样率——本来就是 16k，所以其实没代价。
> 但 Arduino 的 `ESP_I2S` 封装不太支持同时开收和发，要用 IDF 的 `i2s_std` 原始 API 才行。

## 二、三个模块的关键参数

### INMP441（麦克风）

| 项 | 值 |
|---|---|
| 接口 | I2S，**只能当从机**（时钟由 ESP32 给） |
| 数据格式 | 24bit 数据放在 32bit 帧的高位 |
| 采样率 | 16000 Hz |
| 声道 | `L/R` 接 GND = 左声道 |
| 读完怎么转 | `int16_t s = raw32 >> 16;` |

```
INMP441        ESP32-S3
VDD   ───────── 3.3V     ← 一定要 3.3V，不要接 5V
GND   ───────── GND
L/R   ───────── GND      ← 接地 = 左声道
SCK   ───────── GPIO41
WS    ───────── GPIO42
SD    ───────── GPIO40
```

**常见故障**：全是"沙沙"声 → 时钟没起来或 VDD 接错；声音很小 → 增益问题，软件里乘个系数（2~4 倍）就行。

### MAX98357A（功放）

| 项 | 值 |
|---|---|
| 接口 | I2S，从机 |
| 采样率 | 16000 Hz，16bit，单声道 |
| 增益 | 默认 9dB；`GAIN` 脚悬空即可 |
| 声道选择 | `SD` 接 GND = 左声道（配合我们只发左声道） |

```
MAX98357A      ESP32-S3
VIN   ───────── 5V       ← 接 5V，音量比 3.3V 大一截
GND   ───────── GND
LRC   ───────── GPIO21
BCLK  ───────── GPIO14
DIN   ───────── GPIO47
SD    ───────── GND      ← 左声道，且不静音
GAIN  ───────── 悬空
```

**常见故障**：有节奏的"咔哒"声 → 数据供不上（DMA 缓冲太小或网络太慢）；一边没声 → `SD` 接错。

### OV2640（摄像头）

| 项 | 值 |
|---|---|
| 分辨率 | QVGA 320×240（够模型看，也够小） |
| 格式 | JPEG，质量 10~12 |
| XCLK | 20MHz |
| 一帧大小 | 8~20KB |
| 一帧耗时 | 100~300ms |

引脚用你板子厂家例程里的（各家不一样），典型值见文首表格。

## 三、供电方案

没有电机之后，供电一下子简单了：**没有大电流冲击，就不用和浪涌较劲**。

```
 单节 18650 (3.7V, 满电 4.2V) 或 2S (7.4V)
      │
      ├──► 降压 / 升压到 5V 2A ──► MAX98357A VIN（功放是唯一的耗电大户）
      │                     └──► 开发板 5V（板载 LDO 再出 3.3V）
      │                              ├──► INMP441 VDD
      │                              └──► OLED VCC
      └──► 电池分压 → GPIO48（检测电量）
```

**要做的三件事**：

1. 功放电源并 **470µF 电解 + 100nF 陶瓷**（声音大时电流会跳，不加会有杂音）
2. 所有地**星形汇到电池负极**，麦克风的地别串在功放后面
3. 电池分压电阻用 **220k / 100k**（4.2V → 1.3V，单节电池就够安全），ADC 脚并 100nF

续航估算：一节 18650（3000mAh ≈ 11Wh），屏幕 + 主控待机约 0.6W，说话时约 2W → **待机十几小时，一直聊天 4~5 小时**。
比带轮子的版本轻松很多，一节电池就够。

## 四、固件的工作分解

按顺序做，每一步都能独立验证。**不要跳步**。

### 任务 1 · 联网与串口（半天）

- WiFi 连接，串口每秒打印 IP
- 用 `HTTPClient` 打一次 `/robot/api/ping?id=robot-1`，打印返回值
- **完成标准**：串口能看到 `{"ok":true,"name":"小豆"...}`

> 这一步通过，说明网络、地址、token 全对。后面所有问题都不在网络上。

### 任务 2 · 录音（1 天）

- `ESP_I2S` 初始化：16kHz、32bit slot、单声道、只读
- 录 3 秒到 PSRAM（`ps_malloc`，3 秒 16k×2 = 96KB）
- 按 `>> 16` 转成 int16，套 WAV 头发到电脑，用播放器听
- **完成标准**：电脑上能听清自己说的话，没有明显杂音

> 先录到 PSRAM 再处理，不要边录边发。调试期看得见数据最重要。

### 任务 3 · 端点检测（半天）

不是一直传音频，而是"检测到说话才开始，静音 800ms 就结束"：

```
每 20ms 取一块 → 算 RMS → 
  RMS > 阈值(约 800~1500，按环境调) 且持续 > 200ms  → 开始录音
  录音中，RMS < 阈值持续 800ms                      → 结束，进入上传
  录音超过 8 秒还没停                                → 强制结束
```

**完成标准**：说一句话，串口打印 `录音 2.3 秒`；不说话时永远不触发。

### 任务 4 · 上传与播放（1~2 天）

这是**整个固件最关键的一段**：

```
POST /robot/api/turn
  → 读响应，一直读到 '\n' 之前 → 这是 JSON 头
  → 解析出 actions（存起来，先不执行）
  → '\n' 之后的字节全是 PCM → 每收到 512 字节就写进 I2S
```

要点：
- **不要在内存里攒完整段音频**。一边收一边播，延迟才低，内存也够
- 用 `HTTPClient::getStreamPtr()` 拿到裸流，自己 `readBytes`
- 播放前先写 2~3 个静音块，避免功放启动爆音
- 播完再执行 actions

**完成标准**：说"你好"，2~5 秒内听到回答。

### 任务 5 · 脸（1 天）

这是这台机器人最有个性的部分：**屏幕上的一张脸**。

- 用 `U8g2` 驱动 72×40 的 SSD1306，全屏刷新一次约 5~10ms，10fps 很轻松
- 表情表照抄 `plugin/lib/face.js`（面板里的预览就是照它画的，所见即所得）
- 每个表情 = 眼型 + 眼高 + 眼宽 + 倾斜 + 嘴型，五个参数
- 眨眼：`blink:true` 时每 3~6 秒把眼睛压成一条线 120ms，只在 `open` 眼型时眨
- 动画：说话时嘴型在 `talk` 的两个高度之间来回，10fps 就够
- 说话时嘴动、聆听时眼睛放大、思考时眼睛半闭——这些**不需要服务端下指令**，固件按本地状态（录音中 / 播放中）自己切换

```
收到 actions 里有 {type:"face", emotion:"happy"} → 切表情，保持到下一次切换
ping 回来的 face.emotion                      → 这是「心情」，空闲时用
本地状态（录音 / 播放）                        → 临时盖住心情，结束后回到心情
```

> 电量低于 15% 时自动切到 `sleepy`，这比弹一个电池图标自然得多。

### 任务 6 · 视觉（1 天）

- 按 `robot_look` 的时机抓一帧：可以在每次上传音频前顺手抓一张，`POST /robot/api/frame`
- 分辨率 320×240、质量 10，20KB 左右

### 任务 7 · 电量与低功耗（半天）

- 每 30 秒读一次 ADC，换算成百分比，放进 ping 的 query
- 电量 < 15% 时：主动说一句"我快没电了"，然后降低亮度、关闭摄像头

### 任务 8 · 稳定性（1 天）

- 看门狗：主循环超过 10 秒没喂狗 → 重启
- 断网重连：WiFi 掉了自动重连，串口打印重连次数
- 连续说 50 句不崩、不漏内存

## 五、开发环境

推荐 **PlatformIO + Arduino 框架**（ESP32 core 3.x），原因：库多、`HTTPClient` / `ESP_I2S` / `esp_camera` 都现成，不用自己啃 IDF。

```ini
[env:esp32s3]
platform  = espressif32
board     = esp32-s3-devkitc-1
framework = arduino
board_build.arduino.memory_type = qio_opi
board_build.flash_mode = qio
board_build.psram_type = opi
board_upload.flash_size = 16MB
board_build.partitions = default_16MB.csv
build_flags =
    -DBOARD_HAS_PSRAM
    -DARDUINO_USB_MODE=1
    -DARDUINO_USB_CDC_ON_BOOT=1
monitor_speed = 115200
lib_deps =
    esp32-camera
```

> `qio_opi` / `opi` 这两行是 N16R8 的关键，写错了 PSRAM 就用不了，摄像头会直接失败。

## 六、上板调试的顺序（血泪版）

1. 只烧 WiFi 例程 → 串口有 IP
2. 只烧摄像头例程 → 能拍照（**先别接麦克风和功放**）
3. 接麦克风 → 录音能听清
4. 接功放 → 放正弦波没爆音
5. 接电机 → 正反转（**先别装轮子**，看电机轴）
6. 全部接上 → 先只测"说话"，再测"动"
7. 装轮子 → 限速 30%，试跑

**任何时候出现"一动就重启"，先怀疑电源，不要怀疑代码。**
