# 插件用法：在 DSH 里养一只机器人

## 它在哪

**左侧栏的「机器人」图标**（和「插件」「自动化任务」「Aurabot」在同一列，点它中间那栏就切到机器人页面）。

设置里也留了一个入口（设置 → 机器人），两个地方是同一份配置。

面板里改的东西都存在：

```
%USERPROFILE%\.dsh\plugins-data\esp32-robot\config.json
```

出问题第一时间看这个文件，比看面板快。

---

## 面板上的每一块

### 状态

| 控件 | 干什么 |
|---|---|
| 名字 | 它给自己的称呼（也会进提示词） |
| 总开关 | 关掉 = 设备接口直接拒绝，不发消息不动 |
| 最近一轮 | 上一次它听到了什么、说了什么、用了多久 |
| 重新开始一个新会话 | 清空对话记忆，下次说话是崭新的（人格配置保留） |
| 打开模拟器 | 用电脑麦克风/喇叭当机器人，见下 |
| 试一句 | 让它说一句"介绍一下你自己"，直接听效果 |

### 人格与规则

这里是**唯一需要认真写**的地方。

- 上面的大框是人格正文，会拼在系统提示词最前面
- 下面的「行动规则」是补充约束（默认那段已经写了"你只有动作工具、没有电脑"）

写人格时记住三件事：

1. **它说的话会被念出来**，所以不要写"用 Markdown 列表回答"
2. **一次只说一两句**，写在人格里比任何工程优化都有效
3. **别写它没有的能力**（"你可以上网查"——它不能）

改完点「保存人格」，下一句立刻生效，不用重启。

### 大脑

| 字段 | 说明 |
|---|---|
| provider / model | 留空 = 跟 DSH 当前默认模型一致。填了只影响机器人这个会话 |
| 思考强度 | 语音对话建议 `low` 或不填。`high` 会让首字变慢好几秒 |

> 想对比效果：填 `deepseek-account` / `deepseek-flash` 和 `deepseek-chat` 各试一句。

### 嗓音

| 引擎 | 说明 |
|---|---|
| Windows 系统语音 | 默认。离线、免费、**第一句出声最快**。中文是 Huihui |
| 自建 TTS | 填一个带 `{text}` 的地址，返回 wav 或裸 pcm16。**不支持 MP3** |
| 不出声 | 调试固件时用，只返回文字 |

> 系统语音第一次调用要起一个 PowerShell，约 0.3~0.8 秒。之后每次都要起，这是它唯一的缺点。

### 耳朵

| 方式 | 说明 |
|---|---|
| DSH 内置识别 | 走 DSH 自己的语音识别服务 |
| OpenAI 兼容接口 | 填 `/v1/audio/transcriptions` 地址 + key + 模型名 |
| 不识别 | 只收文字（先用 `text/plain` 调接口） |

> ⚠️ **当前最可能要动的一格**：这台机器上 DSH 还没装语音识别模型。
> 如果模拟器里说话报"还没有装语音识别模型"，两个选择：装官方 voice-input 插件包，或者在这里填一个云端识别接口。

### 心情与表情

这是它最有个性的一块。屏幕上是一双眼睛和一张嘴，情绪就靠这两样表达。

| 控件 | 干什么 |
|---|---|
| 心情模块 | **总开关**。关掉之后它不会自己换表情，模型也拿不到 `robot_face` 工具，屏幕固定平静 |
| 现在：xxx | 它此刻的心情和原因（比如「开心 · 面板手动」） |
| 那一排表情按钮 | 点一下**立刻**让它做给你看，同时改掉当前心情 |
| 左边的小屏预览 | 和固件用的是同一张表情表，所见即所得 |
| 多久回平静 | 设成 N 分钟后自动回到 `neutral`；0 = 不回落 |
| 夜里会困 | 23:00~06:00 自动变 `sleepy` |
| 自己换表情 | 允许模型主动调 `robot_face`；关掉后它只能用系统给的固定表情 |

表情表（十个，固件照这张表画）：

| 名字 | 表情 | 眼型 | 嘴型 |
|---|---|---|---|
| `neutral` | 平静 | 睁眼 | 一条横线 |
| `happy` | 开心 | 弯月笑眼 | 上弯 |
| `excited` | 兴奋 | 大弯眼 | 张嘴 |
| `curious` | 好奇 | 睁大 + 歪 | 小圆点 |
| `thinking` | 思考 | 半闭 | 一条横线 |
| `listening` | 聆听 | 睁到最大 | 小圆点 |
| `speaking` | 说话 | 睁眼 | 上下动 |
| `sleepy` | 困 | 闭眼一条线 | 小圆点 |
| `sad` | 难过 | 半闭 + 下垂 | 下弯 |
| `confused` | 困惑 | 睁眼 | 波浪 |

> 首尾坐标写死在 `plugin/lib/face.js` 的 `SCREEN` 里（72×40 画布、左右眼中心 x=24/48、y=16、嘴 y=30），
> 固件按同样的坐标画，两边看到的就是同一张脸。

### 长期记忆

用你装好的 **Mnemon**，分两层：

| 层 | 工具 | 存哪 | 状态 |
|---|---|---|---|
| **热记忆** | `mnemon_runtime_memory` | `~/.mnemon/workspaces/2741dd16…/runtime/{USER,MEMORY}.md` | ✅ 已好用，每轮自动注入 |
| **结构化记忆** | `mnemon_remember` / `mnemon_recall` / `mnemon_related` | `~/.mnemon/workspaces/2741dd16…/data/default/mnemon.db` | ✅ 空间已建好并激活，当前 0 条 |

| 控件 | 干什么 |
|---|---|
| 长期记忆 | 关掉后它只记得当前这轮对话，问「上次那个」会说记不住，记忆工具也从它眼前消失 |

**热记忆里现在已经有三条**（它自己记的，不是迁进去的）：喜欢深蓝色 / 猫叫团子 / 周三羽毛球课。

**结构化记忆**：`小豆的记忆` 这个空间建在**它自己的工作区**里，已激活，目前是空的。
之前建不了是因为本机没有 Memory Provider，装好官方 CLI 并重启后就好了：

```
%LOCALAPPDATA%\pnpm\bin\mnemon.exe       ← 原生二进制，14.9 MB，mnemon version 0.2.13
%LOCALAPPDATA%\pnpm\bin                   ← 已加进用户 PATH
...\dsh-runtimes\...\node\bin             ← 已加进用户 PATH（npm 包的外壳脚本需要 node）
```

> ⚠️ 一个坑：**换工作目录不等于换记忆库**。用子会话（cwd 指到机器人的工作区）建空间，
> 建出来的会落在子会话自己的库里（当时误建到了 default-workspace，已停用）。
> 空间必须由**绑定那个工作区的会话自己**建——也就是让机器人自己调 `mnemon_memory_body_create`。

> 如果建空间还是被拒绝（提示当前视图没有权限），去「记忆系统」页面手动建一个同名的，再回来。

**关于 Documents**：`mnemon_document_*` 不需要 Provider，能建也能搜——但它没有按工作区隔离（会落到
default-workspace 的库里），而且当前视图只允许建、不允许改。所以没有拿它当机器人的记忆主通道。

### 权限（受限指令）

三个勾选框对应三个工具。**关掉不是"拒绝执行"，是模型根本看不到这个工具。**

| 开关 | 工具 | 关掉之后 |
|---|---|---|
| 表情 | `robot_face` | 脸上永远是平静（心情模块关掉时这一项也会变灰） |
| 联网搜索 | `robot_search` | 查不了新东西，只能凭记忆答 |
| 看画面 | `robot_look` | 看不见 |

「搜索条数」是硬上限：单次最多带几条结果给模型参考。旁边的**检查联网**按钮会真的发一次搜索——
如果这台 DSH 还没配搜索密钥，它会直接告诉你（见下面常见问题）。

### 设备接入

| 项 | 说明 |
|---|---|
| 对话接口 | 完整地址，抄进固件 |
| 口令 | `rt_xxxx`，等于门钥匙。烧进固件，泄漏了就在这换一个 |
| 采样率 | 设备上传的采样率，默认 16000 |
| 在线设备 | 谁连过、电量多少 |

## 模拟器

面板里点「打开模拟器」，或者直接访问 `http://<你的DSH地址>/robot/sim`。

- **按住说话**：用电脑麦克风录 16k 单声道，发给 `/robot/api/turn`，用电脑喇叭播放回答
- **打字发送**：跳过识别，直接测大脑 + 语音

它和真机用的是**同一个接口、同一套参数**。模拟器能跑通，固件只要照抄请求格式就行。

## 它现在会什么

| 能力 | 说明 |
|---|---|
| 说话 | 回复被切成句子，边合成边发，第一句最快出来 |
| 听 | 16k PCM 进来，转成文字再交给大脑 |
| 表情 | 十种情绪，屏幕上的一双眼睛和一张嘴 |
| 心情 | 会自己淡掉，也会夜里变困；可以整个关掉 |
| 记忆 | 跨会话记得住你告诉它的小事（Mnemon 热记忆） |
| 查资料 | `robot_search`，要看 DSH 有没有配搜索密钥 |
| 看 | 需要设备上传过画面，否则明确说看不见 |
| 自检 | `robot_status` 永远可用 |

## 常见问题

**Q：面板里没有「机器人」这一项？**
插件没加载。重启 DSH；还不行就看 DSH 的日志里有没有 `[esp32-robot]` 开头的报错。

**Q：点「试一句」报错？**
把鼠标停在红字上看完整信息。常见的是模型没配、或会话创建失败。

**Q：它说「换了表情」但屏幕没变 / 心情没变？**
先看「最近一轮」里的 `actions`。空的说明它只是嘴上说了。多半是工具没挂上——把插件关掉再打开一次
（插件管理里那个开关），然后点「重新开始一个新会话」。工具是挂在会话上的，旧会话会占着旧工具。

**Q：点「检查联网」说不通？**
这台 DSH 里没有搜索密钥。两条路：① 在 DSH 设置 → 模型 / 网页搜索里填 DeepSeek API Key；
② 留着不用——它现在遇到查不了的会老实说「我查不到」，不会编。插件本身不需要额外配置。

**Q：它说话像机器人念稿？**
换音色（刷新列表看有没有别的），或在自建 TTS 里填一个更好的引擎。

**Q：它老是说很长？**
人格里加一句「一次只说一两句，说完就停」。这比改代码管用。

**Q：模拟器能说话，真机不行？**
说明大脑和嘴巴没问题，问题在网络/格式。用 `curl` 打一次接口对比。

## 给别的插件留的接口

别的 DSH 插件可以 `ctx.get('esp32robot')` 拿到：

```js
esp32robot.say('该吃药了')        // 让它主动说一句
esp32robot.devices()              // 当前在线的设备
esp32robot.config()               // 当前配置
esp32robot.resetSession()         // 清空对话记忆
```
